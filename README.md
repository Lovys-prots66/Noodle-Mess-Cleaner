### Noodle Mess Cleaner

A node.js file organizer that takes a directory in either the two ways:

- [1] : By moving files into a new directory where they would be cleaned up
- [2] : By cleaning up the directory itself

Files will be organized by categories (check type.json) depending on their extensions

## Steps:
1. Install this project
1. Open a terminal and navigate to the folder
1. Run:
```bash
    npm link
```
4. Then run:
```bash
    organizer
```
